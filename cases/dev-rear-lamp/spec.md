# spec: Rear Lamp

## Product Type

Rear lamp  — exterior lighting & signalling module combining multiple light functions, lens, and retro-reflector in a single housing.

## Vehicle Category

M1 — passenger car. UNECE lighting regulations referenced apply across M and N categories.

## Function

- Rear position signalling (presence/visibility)
- Braking indication (stop lamp)
- Reversing illumination
- Passive conspicuity (retro-reflector)
- Light transmission & color definition (outer lens)

## Main Parts

- Rear position lamp
- Stop lamp
- Reversing lamp
- Outer lens
- Retro-reflector

## Materials

Representative values — confirm against actual bill of materials.
