# spec: Protective Bicycle Helmet

## Product Type

Bicycle helmet — personal protective equipment for cyclists providing head impact protection, retention, and ventilation. Not a vehicle component; intended for use by riders of L-category vehicles and bicycles.

## Vehicle Category

Not applicable — personal protective equipment. Rider of L1e, L3e (two-wheel motor vehicles) and pedal cycles.

## Function

- Head impact energy absorption (crash protection)
- Retention on the head (chin strap and buckle)
- Ventilation (airflow channels)
- Visibility enhancement (optional reflective elements)

## Main Parts

- Outer shell
- EPS liner (energy-absorbing foam)
- Retention system (chin strap, buckle, adjustment wheel)
- Ventilation channels
- Padding / comfort liner
- Optional: rear reflective strip

## Materials

| Component         | Typical material(s)                  |
| ----------------- | ------------------------------------ |
| Outer shell       | PC (polycarbonate) or ABS            |
| EPS liner         | Expanded polystyrene foam            |
| Chin strap        | Nylon webbing                        |
| Buckle            | ABS or Delrin                        |
| Comfort padding   | EVA foam with polyester fabric       |
| Reflective strip  | Retroreflective sheeting (optional)  |
